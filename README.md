# 🍔 Byte2Bite

Byte2Bite is a responsive frontend website for an online food ordering platform. The project provides a simple and attractive interface for exploring food items and interacting with the website.

## 🚀 Features

* Responsive food ordering website
* Clean and user-friendly interface
* Food and burger product sections
* Attractive food images and visual design
* Responsive layout for different screen sizes
* Simple HTML and CSS implementation

## 🛠️ Technologies Used

* HTML5
* CSS3

```text
└── README.md
```

## 💻 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/rajvaishnav6/Byte2Bite.git
```

2. Open the project folder.

3. Open `Index.html` in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.
